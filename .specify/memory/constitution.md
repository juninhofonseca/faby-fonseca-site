# Constituição - Faby Fonseca Fotografia

## Princípios
- Idioma: português do Brasil em todo o conteúdo e na interface.
- Mobile first: a maioria dos visitantes chega pelo celular.
- Desempenho: imagens otimizadas (WebP, tamanhos responsivos, lazy loading). Meta: página inicial carregando em menos de 3 segundos em 4G.
- Acessibilidade: texto alternativo em todas as imagens, contraste adequado, navegação por teclado.
- Simplicidade: sem dependências desnecessárias. Preferir HTML, CSS e JavaScript simples, ou um único framework leve.
- Custo: hospedagem gratuita ou de baixo custo, compatível com o orçamento de um MEI.
- Privacidade: dados de clientes (nome, telefone, e-mail) tratados conforme a LGPD. Coletar só o necessário.
- Marca: manter a identidade visual da Faby Fonseca Fotografia (cores, tipografia e tom de voz a definir).
